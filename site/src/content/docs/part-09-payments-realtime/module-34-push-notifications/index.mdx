**Part 9: Payments and real time**

## What you will be able to do

After this module you can notify people about payments even when the app is closed.

## What this module covers

- How push works
- Firebase Cloud Messaging for Android
- In-app alerts on macOS
- Device tokens
- Sending from Spring Boot
- Notification settings
- Bonus: Apple Push Notification service for macOS (needs an Apple Developer membership)

## Mini-project

A notification for every payment and decline
