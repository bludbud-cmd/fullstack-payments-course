## What you will be able to do

After this module you can move money between accounts so that it is never lost, created or charged twice.

## What this module covers

- Exact amounts with BigDecimal and integer cents
- A double-entry ledger
- Database transactions
- Locking when two payments hit one account
- Idempotency keys
