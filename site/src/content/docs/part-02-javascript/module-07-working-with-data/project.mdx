Build a small but complete program: an array of objects, kept in memory while it runs and saved as JSON in between. It is a tiny version of what the PayDeck API does with its database.

## What it does

```
0 contacts loaded.
> add Asha Rao, asha@example.com
Added Asha Rao <asha@example.com>
> add Ben Okafor, ben@example.com
Added Ben Okafor <ben@example.com>
> list
1. Asha Rao <asha@example.com>
2. Ben Okafor <ben@example.com>
> find ben
Ben Okafor <ben@example.com>
> delete 1
Deleted Asha Rao <asha@example.com>
> quit
```

Run it again, and `1 contacts loaded.`: the data survived.

## Requirements

1. Contacts are objects `{ name, email }` in an array.
2. On start, load the array from `contacts.json` if the file exists; otherwise start with an empty array.
3. Commands:
   - `list` shows every contact, numbered from 1.
   - `add Name, email` adds a contact, after checking that both parts are there and the email contains `@`.
   - `find text` shows contacts whose name or email contains the text, ignoring upper and lower case.
   - `delete number` deletes the contact with that number from `list`, after checking the number is valid.
   - `quit` ends the program.
   - Anything else shows the list of commands.
4. Save to `contacts.json` after every change.

Write it in `contacts.mjs` and use the reading code from the Module 5 mini-project. In a `.mjs` file, load the file tools with `import * as fs from "node:fs";` instead of `require`.

<Fragment slot="solution">

```js
import * as fs from "node:fs";
import * as readline from "node:readline/promises";

const FILE = "contacts.json";
const terminal = readline.createInterface({
  input: process.stdin,
  output: process.stdout,
});

function load() {
  if (!fs.existsSync(FILE)) return [];
  return JSON.parse(fs.readFileSync(FILE, "utf8"));
}

function save(contacts) {
  fs.writeFileSync(FILE, JSON.stringify(contacts, null, 2));
}

function show(contact) {
  return `${contact.name} <${contact.email}>`;
}

function search(contacts, text) {
  const wanted = text.toLowerCase();
  return contacts.filter(
    (c) => c.name.toLowerCase().includes(wanted) || c.email.toLowerCase().includes(wanted),
  );
}

let contacts = load();
console.log(`${contacts.length} contacts loaded.`);

while (true) {
  const command = (await terminal.question("> ")).trim();

  if (command === "list") {
    contacts.forEach((c, i) => console.log(`${i + 1}. ${show(c)}`));
  } else if (command.startsWith("add ")) {
    const [name, email] = command.slice(4).split(",").map((part) => part.trim());
    if (!name || !email || !email.includes("@")) {
      console.log("Use: add Name, email@example.com");
    } else {
      contacts.push({ name, email });
      save(contacts);
      console.log(`Added ${show({ name, email })}`);
    }
  } else if (command.startsWith("find ")) {
    const found = search(contacts, command.slice(5));
    console.log(found.length ? found.map(show).join("\n") : "Nobody found.");
  } else if (command.startsWith("delete ")) {
    const number = Number(command.slice(7));
    if (!Number.isInteger(number) || number < 1 || number > contacts.length) {
      console.log("No contact with that number. Try list first.");
    } else {
      const [removed] = contacts.splice(number - 1, 1);
      save(contacts);
      console.log(`Deleted ${show(removed)}`);
    }
  } else if (command === "quit") {
    break;
  } else {
    console.log("Commands: list, add Name, email, find text, delete number, quit");
  }
}

terminal.close();
```

A few things here are new:

- `fs.existsSync(FILE)` checks whether the file is there before reading it.
- `contacts.forEach((c, i) => ...)` is like `map` without collecting results; the second parameter, `i`, is the index.
- `const [name, email] = ...` is destructuring for arrays: the first item goes into `name`, the second into `email`.
- `contacts.splice(number - 1, 1)` removes one item at that position and returns the removed items in an array, so `const [removed]` takes the first.

The numbers people see start at 1, but indexes start at 0, hence `number - 1`.
