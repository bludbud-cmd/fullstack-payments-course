**Goal:** By the end of this lesson you can store values in variables, update them, and know when to use `const` and when to use `let`.

## Why it matters

Programs remember things while they run: the amount someone typed, the balance the server sent, whether a card is frozen. They keep each of these in a **variable**. The PayDeck app has hundreds of them, and good names are what make that code readable.

## The idea

A **value** is a piece of data: `25`, `"Corner Café"`, `true`. A **variable** is a name for a value, like a labelled box.

```js
const cardName = "Everyday";
```

Read it as: "create a box called `cardName` and put the string `"Everyday"` in it". The `=` means **put into**, not "equals" as in maths.

JavaScript has two ways to make a variable:

| Keyword | Can you put a new value in later? | Use it for |
| --- | --- | --- |
| `const` | No | Almost everything. Values that will not change |
| `let` | Yes | Values that must change, such as a running total |

Use `const` by default. When you read code and see `const`, you know that name means the same thing all the way down, which makes code much easier to follow. Switch to `let` only when you need to.

### Naming

- Names are written in **camelCase**: first word lowercase, each following word capitalised: `balanceCents`, `isFrozen`, `spendingLimit`.
- Make names say what they hold: `topUpAmountCents` beats `x` or `amt2`.
- Names are case-sensitive: `total` and `Total` are different variables.
- Names cannot start with a number or contain spaces or dashes.

## Worked example

Create `wallet.js`:

```js
const ownerName = "Asha";
let balanceCents = 10000;

console.log(ownerName, "has", balanceCents, "cents");

balanceCents = balanceCents + 2550;
console.log("After a top-up:", balanceCents);

balanceCents = balanceCents - 1200;
console.log("After coffee:", balanceCents);
```

Run it with `node wallet.js`:

```
Asha has 10000 cents
After a top-up: 12550
After coffee: 11350
```

Line by line:

- `const ownerName = "Asha";` The owner never changes, so `const`.
- `let balanceCents = 10000;` The balance will change, so `let`. It is in **cents** (10000 cents is $100.00); you will see why in the next lesson.
- `balanceCents = balanceCents + 2550;` Read the right side first: take the current value (10000), add 2550, then put the result (12550) back into the box. There is no `let` this time: the box already exists.

## Common mistakes

<Aside type="caution" title="ReferenceError: balance is not defined">
You used a name that was never created, often a typo (`balance` instead of `balanceCents`), or a variable used before the line that creates it. Code runs top to bottom.
</Aside>

<Aside type="caution" title="SyntaxError: Identifier 'balanceCents' has already been declared">
You wrote `let balanceCents` twice. Create a variable once with `let` or `const`; after that, just use its name.
</Aside>

## Recap

- A **variable** is a name for a value. `=` puts a value into it.
- Use `const` by default and `let` only for values that must change.
- Name variables in camelCase, saying what they hold.
- To update a `let`, write `name = new value` without the keyword.
