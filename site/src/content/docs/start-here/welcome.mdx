Welcome! This course takes you from never having written code to building and shipping a complete app, on your own, at your own pace.

## Who this course is for

This course is for you if you have **never coded before**. You do not need a computer science background or any maths beyond basic arithmetic. You only need to be comfortable using a computer and installing apps.

## What you will build

You will build **PayDeck**, a card and payments app. People who use PayDeck can:

- top up a wallet with a card,
- issue virtual cards, freeze them, and set spending limits,
- pay merchants and see transactions appear live,
- get a push notification for every payment,
- log in with a password or with Google.

PayDeck has two halves, and you build both:

- **The app** that people use, written in React Native. It runs on Android phones and on the Mac.
- **The backend** that stores the data and moves the money, written in Java with Spring Boot.

<Aside type="tip" title="No real money, ever">
Every payment in this course uses Stripe's test mode. No real money moves, and you never need a real card number.
</Aside>

## What you will be able to do at the end

- Read and write JavaScript, TypeScript and Java.
- Build an app that runs on Android and macOS.
- Design a database and build an API in Spring Boot.
- Handle money correctly, so it is never lost or charged twice.
- Add login with a password and with Google, plus rules for who can do what.
- Take card payments, show live updates, and send push notifications.
- Test and deploy everything you build.

## How long it takes

There is no deadline. Go at whatever pace suits you. A few focused hours a week is a good rhythm. Coming back regularly matters more than long sessions.
