## A Mac

Every learner builds the Mac version of PayDeck, and Apple's tools for that only run on macOS. The same Mac also runs the Android emulator, so one computer covers everything.

| | Minimum | Recommended |
| --- | --- | --- |
| Chip | Any Mac that runs the latest macOS | Apple silicon (M1 or newer) |
| Memory | 8 GB | 16 GB or more |
| Free disk space | 40 GB | 60 GB or more |

<Aside type="caution" title="Disk space matters">
Xcode, Android Studio and the Android emulator are large. Clearing space before Module 11 will save you trouble.
</Aside>

An Android phone is useful but not required. The emulator on your Mac works just as well for the course.

## Free accounts

You will create these as you need them. Each lesson that needs one tells you exactly how.

| Account | Needed from | What it is for |
| --- | --- | --- |
| GitHub | Module 3 | Saving and sharing your code |
| Google account | Module 29 | "Sign in with Google" |
| Stripe | Module 31 | Card payments, in test mode only |
| Firebase | Module 34 | Push notifications on Android |

## Optional: Apple Developer Program

Two bonus lessons need a paid Apple Developer membership (99 US dollars a year): push notifications on the Mac, and signing your Mac app so others can install it. **You can finish the whole course without it.** The free route uses in-app alerts on the Mac and runs the app on your own machine.
