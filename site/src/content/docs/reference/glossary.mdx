---
title: Glossary
description: Plain-language definitions of the words used in this course.
---

New words appear here the first time a lesson uses them. Terms are in alphabetical order.

API
: Short for application programming interface. A set of requests one program can send to another. PayDeck's app talks to its backend through an API.

Backend
: The part of a system that runs on a server, away from the person using it. It stores data and does the work the app asks for.

Client
: The program a person uses directly, such as an app on a phone. It sends requests to a server.

Database
: An organized store of data that a program can search and change. PayDeck keeps accounts, cards and transactions in a database.

Frontend
: The part of a system people see and touch: the screens, buttons and forms.

Ledger
: A record of every movement of money. Balances are worked out from the ledger, so money can never appear or vanish without a trace.

Server
: A computer that waits for requests and answers them. Your backend runs on a server.
