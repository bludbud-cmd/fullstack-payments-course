**Part 10: Ship it**

## What you will be able to do

After this module you can put the API online and build the app for others to install.

## What this module covers

- Docker images
- Hosting the API and database online
- Environment variables and secrets
- An Android release build
- Packaging the macOS app
- CI with GitHub Actions
- Bonus: signing and notarizing the Mac app (needs an Apple Developer membership)
